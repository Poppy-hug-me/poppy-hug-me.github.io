这是网络渗透测试课的一次作业，这次的主题是网络空间测绘和子域名收集。

![老师布置的作业要求](/img/cyberspace-task.png)

用大白话说，就是在不接触目标的前提下，通过一些公开的搜索引擎和数据库，把一个域名在公网上暴露的资产摸个大概：它有哪些 IP、开了哪些端口、跑了什么服务，还有它有哪些子域名。全程用 `example.com` 做测试，不会去碰任何没授权的目标。

下面是我这次作业的完整过程。

## 什么是网络空间测绘

先说主角 ZoomEye（钟馗之眼）。它是知道创宇出的一个网络空间测绘引擎，可以检索互联网上暴露的资产、端口和服务。我个人把它理解成"给全世界开着的电脑建了个搜索引擎"，你输入语法，它帮你把公网上的设备翻出来。

功能类似的平台还有不少，做作业的时候顺便整理了一下：

- **FOFA**：国产测绘引擎，语法和 ZoomEye 很相近
- **Hunter（鹰图）**：奇安信出品的
- **Quake**：360 的空间测绘平台
- **Shodan**：国外老牌的物联网测绘引擎
- **Censys**：侧重证书和主机信息的检索

## ZoomEye 实操

先试 ZoomEye。检索语句是：

```
domain:"example.com"
```

作用是检索这个域名下公网暴露的资产，能拿到 IP、端口、Web 服务这些信息。

![ZoomEye 搜索 example.com 的结果](/img/zoomeye-search.jpg)

结果出来 3,927 条，用时 4.3 秒。点开第一条是 lebkuhen-schmidt.com:443，一台位于德国的服务器，应用是 Apache httpd，详情页里能看到它的 IP、组织信息、ASN 和完整的 HTTP 响应头。

需要注意的是，结果里混进了一些看起来和 example.com 并不相关的站点，推测是测绘引擎的 domain 检索把证书、关联资产这类记录也一并算进来了。所以结果数量大不代表都是目标资产，实际使用时还需要自己甄别。

## FOFA 实操

接下来用 FOFA 做个对比，检索语句是：

```
domain="example.com"
```

![FOFA 搜索 example.com 的结果](/img/fofa-search.png)

感觉和 ZoomEye 是两种画风。FOFA 未登录只能看到部分结果（页面上写着"登录后可看"），但能看到的结果就精准很多：出来的就是 example.com 本尊，`https://www.example.com` 和 `https://example.com`，都躲在 Cloudflare 后面，开了 443、80、2053、2083、2087 这些端口，国家/地区排名里美国占 10 个。

对比下来我的感受是：ZoomEye 结果量大但杂，得自己过滤；FOFA 结果更干净，不过想看全得先注册个号。两个各有各的好。

## 子域名收集

子域名收集的常见方法有这么几种：

1. **证书透明度日志查询（crt.sh）**：从 SSL 证书记录里提取子域名，这次实操用的就是它
2. **测绘引擎检索**：ZoomEye / FOFA 的 domain 语法结果里也能提取子域名
3. **被动 DNS 数据库查询**
4. **工具枚举**：subfinder、amass、Sublist3r 这些
5. **搜索引擎 site 语法挖掘**

### crt.sh 实操

crt.sh 的原理是读取全网 SSL 证书日志（CT Log），从证书绑定的域名里提取子域名。查询方式很直接，访问 `https://crt.sh/?q=example.com` 就行。

不过 crt.sh 的稳定性一般，查询过程中多次出现 502 Bad Gateway，刷新了几次才成功查询。

![crt.sh 查询 example.com 的结果](/img/crtsh-search.png)

加载出来之后是一大串证书记录，能看到的域名有 `example.com`、`*.example.com`（通配符证书），还有 `emudhra-lab.example.com` 这样的子域名。签发机构也挺五花八门，GoDaddy、Cloudflare、DigiCert、Sectigo 都有，每条记录都有 Not Before / Not After 的有效期可以看。

SSL 证书在签发的时候就必须把域名写进公开的日志里，不然浏览器不认。所以只要一个子域名配过 HTTPS 证书，它基本就会在 crt.sh 上留下痕迹，这也是它收集子域名特别好用的一方面。

## 总结

- 网络空间测绘引擎可以快速发现目标在公网暴露的资产，但结果要自己甄别，量大的不一定都对
- 子域名收集是信息收集阶段的重要一步，crt.sh 靠证书日志能挖出不少东西，就是网站不太稳定
- 多种方法组合使用才能收集到更多资产，单一来源总有遗漏

实验全程使用 `example.com` 这个测试域名，遵守网络安全规范，没有对任何未授权的目标进行探测。
